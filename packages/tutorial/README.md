# @mpgd/tutorial

Reusable tutorial engine for mpgd games. It provides a DOM-free tutorial
director, platform storage adapter, optional Driver.js presenter, and opt-in
local reproduction helpers. Games keep ownership of tutorial content, gameplay
signals, simulation blocking, localization, and any production replay button.

See the [Tutorial Engine guide](https://github.com/imjlk/mpgd-kit/blob/main/docs/TUTORIAL_ENGINE.md)
for boundaries, API usage, optional replay UI, and the local browser harness.
