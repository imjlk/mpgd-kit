npm/@mpgd/capacitor-storekit: patch (Changed)
---

The Swift package now requires `capacitor-swift-pm` from 8.5.1 up to the next major release instead of exactly 8.5.2, matching the `@capacitor/core` ^8.5.1 peer. A shell on Capacitor 8.6.2, which new games get, resolves the plugin; before, Swift Package Manager refused every shell not on exactly 8.5.2.
