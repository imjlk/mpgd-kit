Optional review providers distinguish opaque native requests from explicit store-page navigation. Add an opt-in target integration, persisted visit/play/cooldown policy, AIT Review.request, Capawesome AppReview for explicitly selected mobile stores, and Microsoft/registered ONE store or Verse8 listing helpers. Unsupported hosts have no prompt or storage activity; no outcome claims that a review was displayed or submitted. Import review adapters by subpath so unused SDKs stay out of browser and inline bundles.
