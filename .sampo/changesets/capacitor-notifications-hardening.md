The Capacitor notifications provider no longer treats a swipe-dismiss as an open, waits for Android notification channels before `register()` returns a token, and refuses that token when a push-only Android shell cannot create the catalog channels. It omits `advertising` from Android remote purposes until an FCM message can carry the opt-out action. An iOS local reminder is confirmed by its key, time, and route, not only its id, and an add still missing after that wait does not fail the schedule or restore an evicted reminder. Android `listLocal` omits a stored row only when it is in the shade, so a Doze-deferred alarm stays cancellable. A newer token wins when overlapping permission corrections would otherwise publish an older one last. A settings change that the last permission read missed is corrected on the next token. iOS provisional or ephemeral authorization, when a shell reports it, stays promptable, and Android notifications turned off in settings read as blocked.
