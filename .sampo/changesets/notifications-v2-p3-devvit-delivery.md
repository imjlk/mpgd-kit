npm/@mpgd/adapter-devvit: minor (Added)
---

`@mpgd/adapter-devvit/server` adds notifications v2 delivery inside the Devvit server. `createDevvitNotificationDeliveryProvider` sends one recipient per `notifications.enqueue` call with the gate's filled title and body and the send's post or comment `link`, and reads `isOptedIn` at send time. It refuses before sending a title over 60 or a body over 100 Unicode code points of the filled text, a link that is not a `t3_` or `t1_` id, and a filled text containing `{{`, which Devvit's Mustache would read as a tag. `failureCount` and `errors` map per recipient: a rate-limit message is `rate-limited`, any other refusal is `rejected` (`classifyEnqueueError` overrides the default), and a call that throws is `ambiguous`. `createDevvitNotificationProviderEntry` is the registry entry, with 2 per user per day as a provider limit and 25,000 per app per day as the `rate`. `createDevvitNotificationService` runs the `@mpgd/game-services/notifications` service with the Redis store and the provider for the `reddit` target, and `devvitNotificationSession(userId)` gives a logged-in user's session. The main entry exports the Devvit profile values (`createDevvitNotificationCapabilities`, the length limits and `devvitNotificationTextLength`).
