---
npm/@mpgd/cli: patch (Fixed)
---

`mpgd game icons generate`, `verify`, and `inspect` no longer fail with `Unknown target: --`, so a generated game's `icons:*` scripts and its Devvit `prepare:icon` scripts now run. The CLI ran the kit's `game:icons:<action>` script as `pnpm game:icons:<action> -- <targets> <profile>`, pnpm 11 and 12 hand that `--` to the script, and the kit's icon runner read it as the target list. The CLI now passes the target list and the profile as plain arguments, and without `--targets` it names every target in `mpgd.targets.json` instead of passing an empty list, so it also works with an older `--kit-path` checkout; a game with no targets gets an error rather than a run that checks nothing. A kit checkout with this fix also skips the `--` that older CLIs pass, and it refuses a target list that names no target (such as `,`) or an argument after the profile. Its runner now prints the `generate` and `verify` result lines and the `inspect` report, which `strip.config.js` had removed as `console.log` debug output. Updating either the CLI or the kit checkout is enough to run the commands; `inspect` output needs the updated kit checkout. Game-side workarounds that call `tools/icons/run.ts` directly can return to the `icons:*` scripts.
