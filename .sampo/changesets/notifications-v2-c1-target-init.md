npm/@mpgd/cli: minor (Added)

`mpgd target init capacitor --providers notifications` adds notifications to an existing game's game-owned Capacitor shell: it installs `@capacitor-firebase/messaging` and `@capacitor/local-notifications` into the shell (at the game's installed versions, else 8.5.2 and 8.3.1) and declares them and `firebase` in the game, syncs a preserved native project, and, when a Capacitor gateway is still the template's (store-wired or not), wires the notifications provider into it and writes the starter modules and catalog the gateway reads, keeping any the game already has. A game-owned gateway is only checked. It refuses a game or shell that lists `@capacitor/push-notifications`, drops `SCHEDULE_EXACT_ALARM` from a newly generated Android project's manifest, and warns about an existing manifest that keeps it, about missing `google-services.json` and `GoogleService-Info.plist`, and that the settings screen is not added to an existing game. `mpgd.native-shell.json` records the plugins under `providers.notifications`.
