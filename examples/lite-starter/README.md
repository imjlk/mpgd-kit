# Lite Starter

Canvas2D lite game generated by `@mpgd/create-game --template lite`.
It uses `@mpgd/lite-shell`, `PlatformGateway`, and the shared mpgd game runtime.

## Start

```sh
pnpm install
pnpm dev
pnpm check
pnpm build
pnpm accept
```

Standalone games install the public `@mpgd/lite-shell` package. Add `--workspace --kit-path <mpgd-kit>` to generate a game linked to a local Kit checkout.
The CLI supports the canvas renderer; DOM and SVG renderers are planned.

## Ownership

- `src/game/state.ts`: deterministic state.
- `src/lite/tapGame.ts`: Canvas2D renderer and input.
- `src/runtime/createGame.ts`: mount, audio binding, and teardown.
- `src/platform`: gateway selection and authoritative services.
- `mpgd.targets.json`: configured target build and feature ownership.

Read `AGENTS.md`, `agent/brief.md`, `agent/acceptance.md`, and `docs/MPGD_KIT_WORKFLOWS.md` before material edits.
Use generated icon, localization, build/smoke, and acceptance commands; preserve their evidence.
Keep SDK calls outside game and renderer code. Backend ledger grants precede durable commerce or rewarded changes.
Never commit platform credentials or signing material.

## Devvit and browser behavior

Inline and expanded entries both use the lite renderer. Preserve feed scrolling and browser touch gestures.
Verify static imports, preloads, and CSS imports against the inline budget; defer optional engines only through explicit dynamic imports.
Returning through browser history must retain a persisted game. Verify resize, DPR, safe areas, lifecycle, and native presentation ownership on configured targets.
Target smoke verifies build artifacts; real SDK and device acceptance is required for platform release evidence.
